## Folder index

- machine-learning/ - ML lab notebook and the eight CSV files it reads.
  - notebooks_withv.ipynb - code and outputs for Questions 1-4.
  - train_data.csv, test_data.csv - Experiment 1.
  - LR_or_PR_china_gdp.csv, fuel_consumption_dataset.csv, Used_Car_Dataset.csv - Experiment 2 runs in the notebook.
  - house_train.csv, house_test.csv - Experiment 3.
  - drug.csv - Experiment 4.

The CSVs are kept beside the notebook because its code loads them by filename.

## Download and open on a college lab PC

1. Open [github.com/JoyPeace04/lab-files](https://github.com/JoyPeace04/lab-files).
2. Click the green **Code** button, then **Download ZIP**.
3. In Windows File Explorer, open **Downloads**, right-click lab-files-main.zip, and choose **Extract All**.
4. Open the extracted machine-learning folder.
5. Open notebooks_withv.ipynb using the lab's Jupyter Notebook app. Keep the CSVs in that same folder.

The notebook uses Python packages pandas, numpy, matplotlib, and scikit-learn.
